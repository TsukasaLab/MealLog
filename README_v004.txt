MealLog Ver.0.04 更新手順

今回の追加機能
・登録済み記録の編集
  - 料理名
  - 日時
  - 自宅 / 外食 / テイクアウト
  - 店舗名
  - 評価
  - メモ
  - 既存写真の削除
  - 新しい写真の追加

・店舗履歴
  - 一覧の店舗名を押すと、その店舗の過去記録を表示
  - 訪問記録数
  - 平均評価
  - 評価済み件数
  - 過去の料理一覧
  - 履歴から各記録の詳細へ移動

SupabaseのSQL更新
・今回は不要です。
・Ver.0.03で place_type / store_name / rating が追加済みなら、そのまま使えます。

注意
