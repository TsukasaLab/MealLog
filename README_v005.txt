MealLog Ver.0.05 更新手順

追加機能
・共有グループ
  - グループ作成
  - 12文字の招待コード
  - 招待コードで参加
  - グループごとの共有
  - PC / スマホなど各端末で同じ共有記録を閲覧
  - 管理者はグループ削除
  - メンバーはグループ退出

・共有する記録
  - 食事登録/編集時に「自分だけ」または共有グループを選択
  - 共有メンバーは同じ記録と写真を閲覧可能
  - 記録を作成した本人だけ編集/削除可能
  - 他メンバーの記録は閲覧のみ
  - 既存の個人記録はそのまま非公開

重要
今回はSupabaseのSQL更新が必要です。
GitHubを更新する前に migration_v005.sql をSupabase SQL Editorで実行してください。

順番
1. Supabase > SQL Editor > New query
2. migration_v005.sql の全文を貼り付け
3. Run query
4. Success. No rows returned を確認
5. GitHubのMealLogで下記を更新
   - index.html を上書き
   - app.js を上書き
   - v005.css を新規追加
6. Commit changes
7. GitHub Pages反映後に Ctrl + F5

触らないファイル
・config.js
・styles.css
・v003.css
・v004.css
・setup.sql

共有の使い方
1. 右上の「共有」（スマホは下部の「共有」）を開く
2. 代表者が「家族」などのグループを作成
3. 表示された招待コードを家族へ伝える
4. 家族は自分のGoogleアカウントでMealLogへログイン
5. 「共有」から招待コードを入力して参加
6. 食事登録時の「共有範囲」で「家族」を選ぶ

仕様
・グループで共有しても、編集・削除は記録した本人のみです。
・メンバーが退出すると、その人がグループへ共有していた自分の記録は「自分だけ」に戻ります。
・管理者がグループを削除すると、そのグループで共有していた記録は各登録者の「自分だけ」に戻ります。
