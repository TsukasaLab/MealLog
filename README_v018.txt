MealLog Ver.0.18 夜桜祭りモック寄せ版

今回の方針
- 採用したイメージに可能な限り近づける
- 夜の屋台背景を強める
- 桜の枝・花びら・左右の屋台のぼりを追加
- 検索 → 食べた場所 → 3つの集計カード → 最近の食事 の順に整理
- 最近の食事カードを写真＋店舗＋価格＋評価＋日付のコンパクト表示へ変更
- 下部の記録CTAをアプリアイコン入りの祭り背景に変更
- スマホでは重なりを避け、情報量を保ちつつコンパクト表示

更新対象
- index.html
- app.js
- sw.js
- v018.css（新規）

反映手順
1. index.html を上書き
2. app.js を上書き
3. sw.js を上書き
