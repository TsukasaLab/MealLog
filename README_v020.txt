MealLog Ver.0.20 画像イメージ寄せ版

基準画像「祭り夜景のMealLogホーム画面」にさらに近づけた版です。

主な変更
- ヘッダーを背景になじむ半透明の夜祭りデザインへ
- 共有ボタンをヘッダーから外し、アカウントメニューへ移動
- アカウントボタンをMealLogマスコット画像に統一
- 基準画像からマスコット部分を装飾素材として追加
- 右上マスコットの配置を基準画像寄りに調整
- 下部CTAのマスコットも基準画像寄りに変更
- 検索 / 食べた場所 / 3集計カードの比率を再調整
- 最近の食事をスマホでも2列表示へ変更
- 食事カードに縦三点ボタンを追加し、通常の編集ボタン群はカード上では非表示
  （編集・削除は詳細画面から可能）
- 最近の食事「すべて見る」で検索・場所絞り込みを解除
- 桜の花びらを左右余白中心に再配置
- 基礎CSSを完全版に同梱し、hidden等の表示制御が欠けないように修正

差し替え時
- index.html
- app.js
- sw.js
- v020.css
- assets/mascot-hero.png
- assets/mascot-bottom.png

確実に揃える場合は完全版一式をGitHubへ反映してください。
