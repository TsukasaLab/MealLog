MealLog Ver.0.11 夜祭りUI

今回の変更
- 採用した夜祭りイメージに合わせて全体をダークな屋台風デザインへ変更
- ヘッダーのM丸アイコンを廃止し、スマホ用MealLogアイコンと統一
- 背景に夜祭り・屋台の画像を使用
- 見出しキャッチコピーは削除
- 検索 → 4つのダッシュボードカード → 最近の食事、というアプリ型レイアウト
- 今月の記録 / 今月の食費 / よく行く店 / 食事追加 を上部に配置
- 食事一覧を横型カードへ変更
- スマホは画像と文字をCSS Gridで完全に別領域へ分け、重なりを防止
- モーダル、共有、店舗履歴も夜祭り色へ統一

更新するファイル
- index.html
- app.js
- sw.js
- manifest.webmanifest
- v011.css
- assets/night-festival-bg.jpg
- icons/* （スマホアイコンと同じデザインを再同梱）

注意
- 価格機能のDB列がまだなら、Ver.0.09に含めた SQL_v009_price_column.sql を先に実行してください。
- 最初の更新時だけ Ctrl+F5 を1回実行してください。
- 以後は通常のF5でも最新版になる設定です。
